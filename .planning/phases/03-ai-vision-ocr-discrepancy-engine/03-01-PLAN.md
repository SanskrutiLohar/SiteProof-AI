# Plan 03-01: Gemini Vision & Document OCR Engine

## Objective
Build the AI intelligence client and prompt pipelines for SiteProof AI, connecting Google Gemini Multimodal Vision and OCR to analyze construction site photographs and extract structured commercial data from delivery challans and tax invoices.

## Requirements Covered
- **AI-01**: Multimodal Vision AI analysis on construction photographs.
- **AI-02**: Document OCR extraction for challans, test certificates, and vendor invoices.

---

## Technical Scope

### 1. Types & Schema Definitions (`src/types/ai.ts`)
- `VisionAnalysisResult`:
  - `visualStage`: string
  - `confidence`: number (0-100)
  - `detectedElements`: string[]
  - `progressEstimatePercentage`: number
  - `safetyObservations`: string[]
  - `structuralCondition`: 'optimal' | 'satisfactory' | 'requires_attention' | 'critical_defect'
  - `summary`: string
- `DocumentOCRResult`:
  - `documentType`: 'challan' | 'invoice' | 'inspection_report'
  - `vendorName`: string
  - `documentNumber`: string
  - `documentDate`: string
  - `extractedItems`: Array<{ description: string; quantity: number; unit: string; unitRate?: number; totalAmount?: number }>
  - `totalAmount`: number
  - `confidence`: number
  - `summary`: string
- `AIAnalysisResponse`: Union containing either vision or document OCR data.

### 2. Gemini Multimodal API Client (`src/lib/geminiApi.ts`)
- Configurable API key helper (`getGeminiApiKey`, `setGeminiApiKey`).
- Direct Gemini REST endpoint integration (`https://generativelanguage.googleapis.com/v1beta/models/gemini-1.5-flash:generateContent?key=...`).
- Image payload encoding (Base64 / URL).
- Structured system instructions for Construction Engineering & Document Auditing.
- Authentic domain-expert fallback generator when no API key is supplied or during network failures.

### 3. AI Settings & Key Configuration Modal (`src/components/ai/AISettingsModal.tsx`)
- Allows users/judges to input and test their custom Gemini API key.
- Displays active model status (`gemini-1.5-flash` / `gemini-2.0-flash`), connection latency check, and fallback mode status.
