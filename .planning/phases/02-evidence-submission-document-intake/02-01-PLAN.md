# Plan 02-01: Evidence Upload Pipeline, Metadata Extraction & Preset Media Library

## Objective
Implement the file intake engine for SiteProof AI, enabling contractors to upload construction site photographs with EXIF/GPS coordinate extraction, upload delivery challans and invoices, load pre-configured realistic construction demo evidence bundles, and manage evidence persistence in `ProjectContext`.

## Requirements Covered
- **EVID-01**: Contractor photo upload with GPS coordinates, timestamp extraction, and milestone tagging.
- **EVID-02**: Document intake for delivery challans, mill test certificates, and vendor tax invoices.
- **EVID-03**: Dual storage strategy (Supabase Storage integration with client-side Base64/Blob URL offline fallback).

---

## Technical Scope

### 1. EXIF & Geolocation Parser (`src/lib/exifReader.ts`)
- Pure client-side metadata extraction utility:
  - Scans JPEG binary buffers for APP1 EXIF marker (`0xFFE1`).
  - Extracts `DateTimeOriginal` / `CreateDate` if present.
  - Extracts GPS Latitude, Longitude, and Reference tags into standard decimal degrees.
  - Exposes browser Geolocation API helper `getCurrentPosition()` with graceful permission handling.

### 2. Sample Evidence Repository (`src/lib/sampleEvidence.ts`)
- Pre-curated authentic construction evidence dataset with realistic high-resolution visuals and complete metadata:
  - **Pier 12 - Reinforcement & Shuttering (Metro Line 4)**:
    - Site Photo 1: *Pier 12 Main Rebar Column Cage with Stirrups Spacing (GPS: 19.1693° N, 72.9515° E)*.
    - Site Photo 2: *Pier Cap Shuttering Alignment & Formwork Inspection*.
    - Delivery Challan: *Ultratech RMC 50 Cu.m M40 Concrete Delivery Challan #DC-2026-0914*.
    - Vendor Invoice: *Tata Tiscon Fe550D TMT Rebar 45 MT Commercial Tax Invoice #INV-2026-4412*.
    - Mill Test Certificate: *NABL Certified Laboratory Tensile & Yield Test Report #TR-550-99*.
  - **Skyline Business Park - Foundation Raft**:
    - Site Photo: *Raft Concrete Pouring & Vibrator Compaction*.
    - Delivery Challan: *ACC Concrete Batching Plant Slip #ACC-RAFT-01*.

### 3. Project Context Evidence Management (`src/context/ProjectContext.tsx`)
- Enhance `ProjectContext` to manage `EvidenceItem` state:
  - `evidence: EvidenceItem[]` (loaded from `localStorage` with initial seeds).
  - `addEvidence: (evidence: Omit<EvidenceItem, 'id' | 'uploaded_at'>) => EvidenceItem`
  - `deleteEvidence: (evidenceId: string) => void`
  - `getMilestoneEvidence: (milestoneId: string) => EvidenceItem[]`
  - `loadSampleEvidenceForMilestone: (milestoneId: string) => void`

### 4. Evidence Upload Modal & Dropzone (`src/components/evidence/EvidenceUploadModal.tsx`)
- Modern drag-and-drop zone supporting photos and PDF/image documents.
- Real-time file preview thumbnail and file size indicator.
- Automatic EXIF GPS/Timestamp detection with visual chip indicators.
- "Use My Current GPS Location" button for live on-site capture simulation.
- Form inputs:
  - Evidence Type: `photo` | `challan` | `invoice` | `inspection_report`
  - Location / Site Sector (e.g. "Pier 12 - Grid C2, East Face")
  - Date & Time Captured
  - Contractor Notes / Field Remarks
  - Linked BOQ Item (select from milestone BOQ list)
- Progress indicator and upload completion feedback.
