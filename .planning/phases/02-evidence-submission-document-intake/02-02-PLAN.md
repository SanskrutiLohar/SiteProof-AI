# Plan 02-02: Evidence Gallery, Chronological Timeline & Milestone Submission Flow

## Objective
Build the contractor and inspector evidence exploration interfaces, including tabbed media galleries, chronological submission timelines, high-resolution inspection lightboxes with GPS map linkage, and milestone submission workflow integration in `ContractorMilestonePage.tsx` and `ProjectDetailsPage.tsx`.

## Requirements Covered
- **EVID-04**: Chronological evidence timeline and tabbed photo/document gallery with preview modals.
- **EVID-01 / EVID-02**: Interactive display of geotagged site photographs, delivery challans, and invoices.
- **PROJ-03 / PROJ-04**: Milestone status transition to `submitted` once contractor compiles evidence.

---

## Technical Scope

### 1. Evidence Card Component (`src/components/evidence/EvidenceCard.tsx`)
- Visual card for individual evidence items:
  - Thumbnail with media type icon badge (`Camera` for photos, `Truck` for challans, `Receipt` for invoices, `ClipboardCheck` for reports).
  - Geotag chip with GPS coordinates & click-to-view map pin.
  - Timestamp indicator (relative and absolute).
  - Uploader attribution pill.
  - Linked BOQ item tag.
  - AI Verification Readiness Badge (`Pending Analysis` / `Processed`).
  - Action buttons: Quick Preview, Delete (if contractor owner).

### 2. Evidence Gallery Component (`src/components/evidence/EvidenceGallery.tsx`)
- Multi-tab filter navigation:
  - **All Evidence** (Total count)
  - **Site Photographs** (Photo grid view with hover zoom)
  - **Delivery Challans** (Material batching tickets)
  - **Tax Invoices** (Vendor commercial invoices)
  - **Test Certificates & Reports** (Lab QA/QC reports)
- View mode switcher: **Grid View** vs **Chronological Timeline View**.
- Empty state with "Upload First Item" and "Load Demo Evidence Pack" shortcuts.

### 3. Chronological Audit Timeline (`src/components/evidence/EvidenceTimeline.tsx`)
- Vertical timeline displaying chronological sequence of submitted items against the milestone deadline.
- Visual connectors, date headers, user badge, and direct thumbnail preview.

### 4. High-Resolution Lightbox Modal (`src/components/evidence/EvidenceLightbox.tsx`)
- Full-screen modal for deep inspection:
  - Large media preview with zoom and pan controls.
  - Side metadata drawer:
    - Evidence Category & Filename.
    - Capture Date & Time.
    - Site Location & Exact GPS Coordinates (with interactive link to Google Maps / OpenStreetMap coordinates).
    - Uploader Name & Role.
    - Linked Contractual BOQ Items.
    - Contractor Field Notes.
    - Placeholder AI Insight readiness status for Phase 3.

### 5. Milestone Submission Action & Page Integration
- Update **`ContractorMilestonePage.tsx`**:
  - Replace the static placeholder with live `EvidenceGallery`, `EvidenceUploadModal`, and `EvidenceTimeline`.
  - Add "Load Authentic Demo Evidence" one-click button.
  - Add "Submit Milestone Package for Verification" CTA button that transitions milestone status from `in_progress` to `submitted`.
  - Summary stats bar: Total Evidence Count, Photo Count, Challan Count, Invoice Count.
- Update **`ProjectDetailsPage.tsx`** (Admin/Inspector view):
  - Add Evidence Tab or expandable Milestone Evidence Drawer allowing inspectors to review uploaded contractor evidence directly from the project cockpit.
