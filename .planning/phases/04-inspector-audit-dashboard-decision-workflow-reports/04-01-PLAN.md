# Plan 04-01: Inspector Verification Cockpit & Certified Human Decision Workflow

## Objective
Build the certified Inspector Verification Cockpit with side-by-side evidence comparison, real-time discrepancy overlays, and the certified human-in-the-loop decision workflow (Approve, Reject, Request Information) with digital signature sign-off and critical discrepancy guardrails.

## Requirements Covered
- **AUDIT-01**: Unified Inspector Verification Cockpit with side-by-side physical vs commercial comparison.
- **AUDIT-02**: Certified Human Decision Workflow (Approve with digital sign-off, Reject with feedback, Request Additional Evidence).
- **AUDIT-03**: Guardrail compliance: Requires human inspector action (no automated bypass) and warns/blocks milestone approval if unresolved critical discrepancies exist.

---

## Technical Scope

### 1. Types & Audit Contracts (`src/types/audit.ts`)
- `MilestoneDecision`:
  - `milestoneId`: string
  - `status`: 'verified' | 'rejected' | 'pending_evidence'
  - `inspectorName`: string
  - `inspectorEmail`: string
  - `digitalSignature`: string
  - `decisionRemarks`: string
  - `checklistChecked`: string[]
  - `decidedAt`: string
- `AuditLogEntry`:
  - `id`: string
  - `milestoneId`: string
  - `projectId`: string
  - `actorName`: string
  - `actorRole`: string
  - `actionType`: 'evidence_uploaded' | 'ai_analyzed' | 'discrepancy_flagged' | 'discrepancy_resolved' | 'inspection_scheduled' | 'inspection_completed' | 'milestone_approved' | 'milestone_rejected' | 'milestone_submitted'
  - `description`: string
  - `timestamp`: string
  - `metadata`?: Record<string, unknown>

### 2. Inspector Decision Modal (`src/components/audit/InspectorDecisionModal.tsx`)
- Human-in-the-Loop decision actions:
  - **Approve Milestone**: Pre-flight verification checklist, digital signature field, auditor remarks, and critical discrepancy blocker checks. Transitions milestone to `verified`.
  - **Reject Milestone**: Mandatory rejection reason and contractor remediation guidance. Transitions milestone to `rejected`.
  - **Request Evidence**: Sends formal information request to contractor.
- Logs decision into `auditLogs` state.

### 3. Inspector Verification Cockpit (`src/pages/admin/InspectorVerificationCockpit.tsx`)
- Accessible via `/admin/verify/:milestoneId` or from project details page.
- **Header**: Milestone title, status badge, contractor details, BOQ baseline total, and action buttons.
- **Dual Synchronized Comparison Workspace**:
  - **Left Pane (Physical Site Progress)**: High-resolution site photographs, GPS tags, capture timestamps, and AI detected visual element cards.
  - **Right Pane (Commercial & Supplier Documentation)**: Delivery challans, vendor tax invoices, NABL lab test certs, and OCR extracted line-item tables.
- **Bottom Verification Bar**: Summary of open discrepancies, 5-stage reconciliation match rate, "Schedule Physical Visit" button, and "Make Official Decision" CTA button.
